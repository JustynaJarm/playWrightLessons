Playwright – ściąga z CSS locators

Przykładowe użycie: page.locator('selector')

1. Najprostsze selektory

page.locator('button')
page.locator('input')
page.locator('a')

Wybiera wszystkie elementy danego typu.

2. Selektor po id

page.locator('#login')

Pasuje do elementu z atrybutem id="login".

3. Selektor po klasie

page.locator('.btn-primary')

Pasuje do elementów z klasą btn-primary.

4. Selektor po atrybucie

page.locator('[type="email"]')
page.locator('[name="username"]')

Wybiera elementy z konkretnym atrybutem.

5. Selektor po tag + atrybut

page.locator('input[type="text"]')
button[type="submit"]

Wybiera określony typ elementu z konkretnym atrybutem.

6. Potomek / dziecko

page.locator('form input')
page.locator('div > span')

form input = wszystkie inputy w formularzu.
div > span = bezpośredni dziecko div.

7. Pierwszy / ostatni / n-ty element

page.locator('li:first-child')
page.locator('li:last-child')
page.locator('li:nth-child(3)')

Przydatne do list i tabel.

8. Wielokrotne klasy

page.locator('.btn.btn-danger')

Pasuje do elementu, który ma obie klasy.

9. Selektory atrybutów z częściami wartości

page.locator('[href^="https"]')
page.locator('[href$=".pdf"]')
page.locator('[data-test*="user"]')

^ = zaczyna się od, $ = kończy się na, * = zawiera.

10. Pseudo-klasy

page.locator('input:enabled')
page.locator('input:disabled')
page.locator('button:focus')

Przydatne do stanu elementu.

11. :has() – element zawiera coś

page.locator('form:has(input[type="submit"])')

Wybiera element, który zawiera inny element.

12. Przykłady z Playwright

await page.locator('#email').fill('test@example.com');
await page.locator('input[type="password"]').fill('secret');
await page.locator('.btn-primary').click();
await page.locator('form input').first().fill('Jan');

13. Praktyczne przykłady

// formularz logowania
await page.locator('input[name="username"]').fill('admin');
await page.locator('input[type="password"]').fill('1234');
await page.locator('button[type="submit"]').click();

// przycisk po tekście
await page.locator('button:has-text("Zapisz")').click();

// element w konkretnym bloku
await page.locator('form.login input').first().fill('Jan');

// pierwszy element z listy
await page.locator('li').first().click();

// link z konkretnym href
await page.locator('a[href="/kontakt"]').click();

14. Najczęstsze wzorce

Po id 
#menu
Po klasie 
.error
Po atrybucie 
[data-testid="save"]
Po tekście 
button:has-text("Zapisz")

15. Przykłady dla tabel

// wybierz wiersz z konkretną wartością w kolumnie
await page.locator('table tbody tr').filter({ hasText: 'Jan Kowalski' }).click();

// wybierz komórkę z konkretnego wiersza
await page.locator('table tbody tr').nth(2).locator('td').nth(1).click();

// wybierz wszystkie wiersze
await page.locator('table tbody tr').count();

16. Przykłady dla checkboxów i radio

// zaznacz checkbox
await page.locator('input[type="checkbox"]').check();

// odznacz checkbox
await page.locator('input[type="checkbox"]').uncheck();

// wybierz radio z konkretną wartością
await page.locator('input[type="radio"][value="male"]').check();

// sprawdź, czy checkbox jest zaznaczony
await page.locator('input[type="checkbox"]').isChecked();

17. Wersja bardziej „lokatorowa” pod testy UI

// najlepszy styl: lokalizuj po data-testid
await page.locator('[data-testid="username-input"]').fill('admin');
await page.locator('[data-testid="password-input"]').fill('1234');
await page.locator('[data-testid="login-button"]').click();

// po id, jeśli jest unikalny
await page.locator('#submit').click();

// po tekście przycisku
await page.locator('button:has-text("Zatwierdź")').click();

// po zawartości bloku
await page.locator('form:has(input[type="submit"])').isVisible();

18. Szybka zasada

Najlepiej wybierać elementy przez:

  • data-testid – najbardziej stabilne
  • id – jeśli jest unikalny
  • class – tylko gdy jest sensownie nazwany
  • zagnieżdżone selektory – gdy nie ma lepszego sposobu
